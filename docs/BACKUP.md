# Бэкап стоковой прошивки (сделай это ПЕРВЫМ ДЕЛОМ)

> EN: Back up your **own** stock firmware before flashing anything — this is
> your personal undo button. Done once (~10 minutes). Never use someone else's
> backup: stock builds differ between production batches. Method: the official
> `picotool` utility dumps the flash; `tools/bin2uf2.py` turns the dump into a
> restore file.

Твоя стоковая прошивка — «заводское состояние» консоли. Она принадлежит
производителю и **не распространяется с этим проектом**, поэтому сохранить её
нужно своими руками. Один раз ~10 минут — и у тебя всегда будет кнопка
«вернуть как было».

## Шаг 0. Скачай два инструмента (один раз)

1. **picotool** — официальная утилита Raspberry Pi.
   `github.com/raspberrypi/pico-sdk-tools/releases` → самый свежий релиз →
   раздел **Assets** → `picotool-…-x64-win.zip` (Windows) или версия для своей
   ОС. Распакуй, запомни, где лежит `picotool.exe`.
2. **Zadig** — `zadig.akeo.ie` (только Windows; на Linux/macOS драйвер не нужен).

## Шаг 1. Драйвер (только Windows, один раз)

Простое перетаскивание `.uf2` работает без драйверов, а вот picotool без
драйвера консоль не увидит.

1. Введи консоль в режим прошивки: **зажми MENU → коротко нажми START**
   (появится диск `RPI-RP2`, см. [INSTALL.md](INSTALL.md)).
2. Запусти Zadig → **Options** → галочка **List All Devices**.
3. Выбери устройство **RP2040** (USB ID `2E8A:0003`) **без буквы диска**.
4. Справа выбери драйвер **WinUSB** → **Install Driver**.
5. Проверка: командная строка в папке с picotool (в адресной строке проводника
   набери `cmd`) → `picotool.exe info` → должен показаться чип RP2040.

⚠️ В Zadig **не трогай** устройство с буквой диска (сам `RPI-RP2`) — драйвер
ставится только на интерфейс без буквы.

## Шаг 2. Снять копию (~1 минута)

Консоль в режиме прошивки, в командной строке из папки с picotool:

```
picotool.exe save -a backup_stock_Jeeree_2026-10.bin
```

(на Linux/macOS — просто `picotool save -a …`)

Пойдёт прогресс-бар, ~30–60 секунд. Получится файл ~2 МБ — это и есть твоя
стоковая прошивка целиком.

## Шаг 3. Сохрани и подготовь к откату

1. Переименуй дамп понятно (например `stock_Jeeree_МОЯ_2026-10.bin`) и **сохрани
   в надёжное место** (облако/флешка/второй компьютер).
2. Чтобы откатываться удобно (перетаскиванием), преврати дамп в файл прошивки:

   ```bash
   python3 tools/bin2uf2.py stock_Jeeree_МОЯ_2026-10.bin stock_Jeeree_МОЯ.uf2
   ```

## Как откатиться на сток

Ровно как установка обычной прошивки ([INSTALL.md](INSTALL.md)): режим
прошивки (MENU→START) → перетащить **свой** `stock_Jeeree_МОЯ.uf2` на диск
`RPI-RP2`. Консоль снова заводская.

⚠️ Помни: наша прошивка хранит игры и сейвы в своей части flash — сток их не
знает и не трогает, но и не показывает. Если жалко сейвы — они останутся в
flash и вернутся вместе с нашей прошивкой.

## Правила

* **Свой бэкап — только свой.** Чужие дампы могут не подойти к твоей ревизии.
* Снимать бэкап стока есть смысл, пока залита стоковая прошивка.
* Повторить процедуру можно сколько угодно раз.
