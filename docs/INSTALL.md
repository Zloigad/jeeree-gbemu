# Установка прошивки — подробный гайд

Здесь всё то же, что в README, но медленно и с пояснениями. Если ты впервые
держишь в руках «железку» — читай по порядку и ничего не пропускай.

## 0. Что тебе понадобится

* Консоль **Jeeree** (сверься с фото в README — они должны совпадать).
* USB-кабель **с данными**. Это главный источник проблем: большинство кабелей
  от телефона/колонки — зарядочные, внутри нет проводов данных. Если диск
  консоли не появляется — меняй кабель в первую очередь.
* Компьютер Windows / Linux / Mac — любой, ставить программы **не нужно**.
* Файл прошивки `.uf2` из раздела
  [Releases](../../releases) — бери самый свежий.

## 1. (Один раз) Сними бэкап стоковой прошивки

**Не пропускай этот шаг.** Это твой личный «откат назад» на случай, если
захочешь вернуть консоль в заводское состояние. 5 минут, делается один раз:
**[BACKUP.md](BACKUP.md)**.

## 2. Введи консоль в режим прошивки

1. Выключи консоль (или просто отключи её от всего).
2. Подключи USB-кабель к компьютеру.
3. **Зажми MENU** и, не отпуская, **коротко нажми START**.
4. На компьютере появится новый диск **`RPI-RP2`** — это заводской загрузчик
   RP2040. Ничего страшного в нём нет: так задумано.

Не появился? По порядку:
* другой кабель (точно «с данными», попробуй от телефона, который точно умеет
  передавать файлы);
* другой USB-порт, лучше напрямую в компьютер, не через хаб;
* повтори жест (зажать MENU → коротко START);
* попробуй другой компьютер.

## 3. Залей прошивку

**Перетащи** файл `gbemu_vX.Y.Z_jeeree.uf2` на диск `RPI-RP2` — как обычный
файл в проводнике. Больше ничего делать не надо:

* диск `RPI-RP2` **исчезнет сам** — значит, всё получилось;
* консоль перезагрузится, появится заставка с номером версии;
* экран **NO ROM** — это нормально: эмулятор есть, а игр пока нет.

⚠️ Не отключай кабель в те 5–10 секунд, пока файл копируется. Если всё же
отключил — ничего страшного: вернись к шагу 2 и повтори.

## 4. Проверь, что всё живо

* Заставка с версией прошивки (например `v9.7.2`) — версия должна совпадать с
  файлом, который ты заливал.
* Кнопки работают: MENU открывает меню, долгое нажатие START выключает
  консоль.

## 5. Добавь игры

См. **[ROMS.md](ROMS.md)** — игры заливаются отдельным файлом-«картриджем»
через тот же режим прошивки.

## 6. Обновление на более новую версию

Ровно то же самое, что шаги 2–3: новые версии заливаются поверх старых,
игры, сейвы и настройки **сохраняются** (со старых версий v9.0 и ниже список
игр пропадёт — пересобери игры заново).

## Если что-то пошло не так

Смотри **[RECOVERY.md](RECOVERY.md)**. Кратко: откатиться или исправиться можно
всегда — просто заново зайди в режим прошивки и залей нужный файл (сток из
своего бэкапа или новую прошивку).
