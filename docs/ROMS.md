# Игры: как добавить свои ROM-ы

> EN: No games are included (legal reasons). Put ROMs of cartridges **you
> own** into `.gb` files and pack them into a games image with
> `tools/make_roms_uf2.py`; flash it the same way as the firmware.

В прошивке **нет ни одной игры** — только заглушка. Это принципиально: ROM-ы
игр распространять нельзя, поэтому каждый собирает библиотеку из своих
собственных дампов картриджей (`.gb`).

## Формат

* Файлы **`.gb`** (оригинальный Game Boy / DMG). Game Boy Color не
  поддерживается.
* Размер одной игры — до 1024 КиБ, всего в консоли живёт несколько игр
  (флеш-память одна на все; точная ёмкость напечатается при сборке).

## Сборка «картриджа» с играми

**Windows:** положи свои `.gb` в папку `Мои игры` рядом со скриптом и запусти
`СОБРАТЬ_ИГРЫ_двойной_клик.bat` (нужен бесплатный Python — скрипт сам
подскажет, если его нет). Готовый файл `games.uf2` появится рядом.

**Linux/macOS/любая ОС:**

```bash
python3 tools/make_roms_uf2.py game1.gb game2.gb game3.gb -o games.uf2
```

## Установка игр

Точно так же, как прошивки: режим прошивки (**зажми MENU → коротко нажми
START**) → перетащить `games.uf2` на диск `RPI-RP2`.

При повторной сборке игр **сейвы сохраняются**, если ты включаешь в новый
набор те же игры (сейвы привязаны к игре). Если игра пропадает из набора —
консоль спросит, чей сейв освободить, и сделает это не молча.

## Замена/добавление игр

Просто собери новый набор (со старыми играми включительно) и залей поверх.

## Откуда взять свои ROM-ы

Только из своих картриджей (рипперы/дамперы — отдельная тема) или из
домашних/свободных игр (например, Libbet, The Magic Floor и другие homebrew
для Game Boy — их авторы раздают бесплатно).
