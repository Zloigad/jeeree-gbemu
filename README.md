# jeeree-gbemu — прошивка-эмулятор Game Boy для карманной консоли Jeeree

![Консоль Jeeree с прошивкой](docs/images/jeeree-console.png)

Альтернативная прошивка для портативной консоли **Jeeree** на RP2040: превращает
её в карманный **Game Boy** со списком игр, сейвами, сейвстейтами и красивым
меню. Прошивка заливается одним файлом без программатора и без установки
каких-либо программ.

> 🇬🇧 English? See **[README.en.md](README.en.md)**.

---

## ⚠️ Прежде чем начать — прочитай это (это важно)

1. **Прошивка только для консоли Jeeree** (на фото выше). Если твоя консоль
   выглядит иначе — **не прошивай**, сначала спроси. Прошивка от другой
   железки не убьёт консоль, но и работать не будет.
2. **Кирпич невозможен.** В RP2040 есть заводской загрузчик прямо в чипе
   (режим BOOTSEL) — его нельзя стереть никакой прошивкой. Если что-то пойдёт
   не так, консоль всегда возвращается в режим прошивки и лечится повторной
   заливкой. Сломать её «навсегда» программно нельзя.
3. **Первым делом сними бэкап СВОЕЙ стоковой прошивки** — это 5 минут и твой
   личный «кнопка отмены»: [docs/BACKUP.md](docs/BACKUP.md). Свой бэкап —
   только свой: не используй чужие файлы отката, стоковые прошивки у разных
   партий различаются.
4. **Никаких игр в комплекте.** В прошивке нет ни одного ROM — только
   заглушка. Игры (файлы `.gb`) ты добавляешь сам из своей коллекции
   (см. [docs/ROMS.md](docs/ROMS.md)). Пиратить не нужно и не предлагаем.

Если после прочтения страшно — гляди [docs/RECOVERY.md](docs/RECOVERY.md):
там описано буквально всё, что может пойти не так, и как это лечится
(спойлер: повторной заливкой).

## 🚀 Установка (5 минут, без установки программ)

Полная версия с картинками: **[docs/INSTALL.md](docs/INSTALL.md)**

**Шаг 0 (один раз в жизни).** Сними бэкап стоковой прошивки: [docs/BACKUP.md](docs/BACKUP.md).

**Шаг 1.** Скачай из [Releases](../../releases) файл `gbemu_vX.Y.Z_jeeree.uf2`
(самый свежий релиз сверху).

**Шаг 2.** Подключи консоль к компьютеру USB-кабелем (**обязательно «с данными»**,
не зарядочным) и введи её в режим прошивки:
**зажми MENU и, не отпуская, коротко нажми START**. Появится диск `RPI-RP2`.

**Шаг 3.** Перетащи файл `.uf2` на диск `RPI-RP2`. Диск исчезнет сам —
консоль перезагрузится. Готово.

**Шаг 4.** Добавь игры ([docs/ROMS.md](docs/ROMS.md)) и играй.

## ✨ Что умеет прошивка

* **Эмулятор Game Boy (DMG)** — полная скорость, звук как в оригинале.
* **Список игр** на несколько штук прямо во flash (переключение без компьютера).
* **Сейвы картриджей** пишутся сами + **2 слота сейвстейтов** (моментальный снимок).
* **Палитры** (включая тёмно-синюю под цвет корпуса), яркость, контраст,
  инверсия оттенков — и всё это **сохраняется при выключении**.
* **Меню**: громкость, звук, перезапуск игры, «проба звука», диагностика.

Требования к играм и ограничения: [docs/ROMS.md](docs/ROMS.md).

## 🛠 Исходники и сборка

Исходники прошивки — в [`gbemu/`](gbemu/) (Arduino IDE) и [`gbemu_pio/`](gbemu_pio/)
(PlatformIO — одна команда). Как собрать самому: [docs/BUILD.md](docs/BUILD.md).

Проверки качества (большой набор автотестов — панель, flash, сейвы, звук,
загрузка, санитайзеры):

```bash
bash tools/check_all.sh
```

CI на GitHub собирает прошивку и гоняет тесты на каждый коммит — бинарники в
Releases собираются из этого же кода.

## ❓ Частые вопросы

**Чёрный экран после прошивки.** Долгое нажатие START (выключение), затем
включить снова. Не помогло — залей файл заново (режим прошивки всегда работает).

**Консоль не видно как диск.** 9 из 10 проблем — USB-кабель без данных.
Попробуй другой кабель/порт, повтори жест MENU→START.

Больше вопросов — в [docs/RECOVERY.md](docs/RECOVERY.md) и в
[Issues](../../issues) (там же можно сообщить о баге).
