# Благодарности и сторонний код / Credits & third-party code

## Peanut-GB (ядро эмулятора Game Boy)

Файл `gbemu/peanut_gb.h` — это
**[Peanut-GB](https://github.com/deltabeard/Peanut-GB)** автора
**[deltabeard](https://github.com/deltabeard)**, распространяется по лицензии
zlib. Ядро адаптировано для этой прошивки (работа из ОЗУ, доработки под
аппаратную часть консоли). Полный текст лицензии — в заголовке файла.

The file `gbemu/peanut_gb.h` is **[Peanut-GB](https://github.com/deltabeard/Peanut-GB)**
by **[deltabeard](https://github.com/deltabeard)**, licensed under the zlib
license. The core is adapted for this firmware (execution from RAM, hardware
integration). Full license text is in the file header.
