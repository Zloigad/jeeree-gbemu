СБОРКА ИГР ДЛЯ КОНСОЛИ JEEREE — готовый набор
=============================================

Что это: программа, которая собирает ТВОИ игры в один файл games.uf2
и заливает его в консоль. Игр в наборе НЕТ (их нельзя распространять) —
ты берёшь свои файлы .gb из своей коллекции.


УСТАНОВКА (один раз, 2 минуты)
------------------------------
Поставь Python: https://www.python.org/downloads/
Большая жёлтая кнопка Download -> запусти установщик со всеми галочками
по умолчанию. Больше ничего ставить не нужно.


КАК СОБРАТЬ ИГРЫ (3 шага)
-------------------------
1) Положи файлы игр (.gb) в папку «Мои_игры_класть_сюда» (она рядом с этим
   файлом) — или выбери их кнопкой в окне программы.

2) Дважды кликни «СОБРАТЬ_ИГРЫ_двойной_клик.bat» ->
   кнопка «Из папки «Мои игры»» -> «СОБРАТЬ games.uf2».
   Готовый файл games.uf2 появится рядом.

3) Залей в консоль:
   - Подключи консоль USB-кабелем (обязательно «с данными»).
   - ЗАЖМИ кнопку MENU и, не отпуская, коротко нажми START —
     появится диск RPI-RP2.
   - Перетащи games.uf2 на этот диск. Консоль перезагрузится — игры на месте.

Сейвы сохраняются, если в новом наборе остаются те же игры.


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
- «Не найден Python» — поставь Python (см. выше): это бесплатно и один раз.
- Игра «только для Game Boy Color» не подойдёт — нужен обычный Game Boy (.gb).
- Сломать консоль невозможно: если что-то пошло не так — зажми MENU,
  коротко нажми START и залей файл заново. Подробности — в гайде репозитория
  (docs/RECOVERY.md).


EN (short)
----------
This kit packs YOUR Game Boy ROM files (.gb) into one games.uf2 for the
Jeeree console. No games included (legal reasons).

1) Install Python 3 from python.org (default options).
2) Put your .gb files into the folder «Мои_игры_класть_сюда».
3) Double-click «СОБРАТЬ_ИГРЫ_двойной_клик.bat», press the green button
   «СОБРАТЬ games.uf2».
4) On the console: hold MENU, tap START — a disk RPI-RP2 appears;
   drag games.uf2 onto it. Done.

Bricking is impossible: the RP2040 boot ROM (BOOTSEL) always lets you
reflash.
